# 望远镜夜间序列规划台

基于 Node.js + Express + 原生前端（Canvas）的望远镜夜间观测序列规划工具。

## 功能

- 录入观测点纬度/经度、日期、目标赤经赤纬、曝光时长、最低高度角
- 在画布上绘制地平线遮挡角轮廓（方位角 → 遮挡高度角）
- 按**地方恒星时**计算每个目标的连续可见窗口（高度 ≥ max(最低高度, 地平线遮挡角)）
- 自动处理**跨子午线翻转**（赤道仪模式）、**窗口重叠**与**转台换向耗时**，生成不冲突的观测顺序
- 无法排入的目标给出具体原因（高度不足 / 地平线遮挡 / 窗口短于曝光 / 与已排目标冲突）
- 时间轴可拖动平移、滚轮缩放；点击目标显示其高度曲线、可见窗口与翻转点

## 启动（单条命令）

```bash
docker compose up --build
```

（旧版 Docker 使用 `docker-compose up --build`）

启动后访问：**http://localhost:3000**（端口 `3000`）

页面打开后点击「载入示例目标」即可获得内置示例站点、山脊遮挡轮廓与 9 个示例目标（含两个演示失败原因的目标），再点「生成观测计划」查看结果。

## 本地开发（不用 Docker）

```bash
npm install
npm start
# 访问 http://localhost:3000
```

## 使用说明

1. **站点与夜晚**：纬度（北正）、经度（东正）、观测日期、暮光标准（民用 -6° / 航海 -12° / 天文 -18°）、转台耗时、翻转耗时、赤道仪/经纬仪模式。
2. **目标列表**：赤经（小时，0–24）、赤纬（度）、曝光时长（分钟）、最低高度角（度）。
3. **地平线遮挡角**：单击空白添加遮挡点并拖动，右键删除点；横轴方位角（北 0°、东 90°），纵轴遮挡高度角。
4. **时间轴**：每行一个目标；绿色半透明为可见窗口，实心绿块为已排观测，红色三角/竖线为子午线翻转点。拖动平移、滚轮缩放、点击行选中目标。
5. **高度曲线**：蓝色为目标高度，橙色虚线为高度限制（最低高度与遮挡角取大者），绿色区域为可见窗口/已排块，红色虚线为翻转点。
6. **观测顺序 / 未排入目标**：给出完整观测序列（含翻转时刻）与每个未排入目标的具体原因。

所有时间轴与结果时间均为 **UTC**。

## API

- `GET /api/samples` — 内置示例站点、地平线轮廓与目标
- `POST /api/plan` — 生成计划。请求体：

```json
{
  "lat": 40.4, "lon": 116.6, "date": "2026-09-21",
  "twilight": "nautical", "mount": "gem",
  "slewMin": 3, "flipMin": 5,
  "horizon": [{ "az": 90, "alt": 16 }],
  "targets": [{ "name": "M31", "ra": 0.712, "dec": 41.27, "exposure": 45, "minAlt": 25 }]
}
```

返回每个目标的可见窗口、翻转点、高度曲线采样、已排块（或失败原因）、完整观测序列。

## 算法要点

- 恒星时：GMST 标准公式 + 经度修正得地方恒星时；目标高度/方位由时角公式计算。
- 黑夜边界：扫描太阳高度，二分细化至暮光阈值穿越点，取 24h 内最长黑夜段。
- 可见窗口：1 分钟步长扫描 + 二分细化边界；高度限制取 `max(最低高度, 地平线遮挡角(方位角))`。
- 翻转点：解 `LST = RA` 得上中天时刻（恒星时近似线性推进）。
- 调度：按「最后窗口结束时间」升序（最早截止优先）贪心插入已排块之间的空档；相邻块强制留出转台耗时；观测块跨过翻转点时块长增加翻转耗时。
